# 黑客松前端模板

这是一个适合黑客松快速启动的前端模板，使用纯 HTML、CSS 和 JavaScript 构建，具有响应式布局、主题切换、导航菜单和模块化样式。

## 文件说明

- `index.html` - 模板入口页面
- `styles.css` - 样式文件，包含响应式和暗黑主题
- `script.js` - 简单交互脚本，包含菜单切换和主题切换

## 使用方式

1. 复制此目录到本地或直接在浏览器中打开 `index.html`
2. 修改文本、颜色和页面结构以适配你的项目需求
3. 如果需要，可引入图标库、动画库或前端框架
